# 主配置目录兼容

新安装使用 `data/config.json`，与人设、模型设置和记忆一起备份。

旧安装通过启动器打开时，先校验根目录 `config.json`，备份到 `data/config.legacy.backup.json`，再复制到新路径；根目录原文件保留。新路径已存在则不覆盖、不合并。

内核、桥接、离线设置、图库和诊断优先使用新路径。直接运行旧源码目录时，如果尚未迁移则继续读写根目录配置；读取本身不改动文件。新路径格式损坏时报告配置错误，不自动恢复旧账号或旧密钥。

迁移失败不会删除旧文件，仍可使用旧路径。配置中相对目录仍以安装根目录解析，不以 data 目录解析。

默认覆盖升级保留 data；只有用户明确选择清除个人数据时才删除。不要只替换 EXE 而漏掉内核、桥接与脚本更新。
