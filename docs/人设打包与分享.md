# 人设打包与分享（4.1.5 开发版）

## 使用

**仅分享提示词**：点击人设页「仅分享提示词」，只导出自定义补充提示词正文，不包含基础身份和页面设置；正文必须非空。包内 persona.json 严格只有 customPrompt，最多 24000 字符且 UTF-8 JSON 不超过 64 KiB，最低客户端 4.1.0，符合当前市场的人设数据格式要求；仍需正常投稿审核，不会自动上架。

下面的「打包分享」导出完整设置：

1. 在人设页编辑内容和表达设置，点击「打包分享」。
2. 确认内容，填写包名、作者昵称、包 ID 和版本，选择 ZIP 保存位置。
3. 对方在「插件市场 → 从本地安装」选 ZIP，再启用。
4. 回到人设页，在预设列表选择新条目并「应用选中预设」。
5. 安装的人设可直接修改，自动保存到本地副本，不必先复制；原始 ZIP 不变。

自建人设在 `data/personas/user-*.json`，一份人设一个文件。插件人设启用记录在 `data/plugins/<id>.persona.json`，本地修改单独在 `data/personas/market-<id>.json`。只有插件启用时市场条目才显示；停用或卸载不清空已经应用的人设。

本地修改优先于同 ID 原始数据，重新启用或更新不覆盖修改；当前不自动合并冲突。选择市场预设后可点击「恢复作者版本」删除本地副本，再应用预设使用作者版本；操作前请备份需要保留的修改。当前已应用的人设不会立即改变。

`data/persona.json` 仍是兼容旧版的当前运行快照，不是分享文件；不要打包整个 `data/`、`config.json` 或运行快照。

## 分享范围

包含名字、年龄、职业、外观、性格、背景、补充提示词、称呼、角色别名、主动顶嘴、主动延伸话题、主动表达观点、颜文字档位与概率、私聊/群聊字数、讨论上限、历史条数、气泡数。

**不包含**主人账号与昵称名单、联系人、群名单、模型密钥、聊天记录、记忆、服务端口或系统权限。称呼、别名和自由文本仍可能含作者自己写入的私人信息，导出前必须检查；白名单不是隐私自动清洗保证。

## 格式

ZIP 根目录只有 `plugin.json` 和 `persona.json`。清单使用 `Api: 1`、`Kind: "persona"`，最低客户端 `MinAppVersion: "4.1.5"`，无执行能力。ID 为小写字母开头的小写字母、数字和短横线，最多 48 位；更新保持 ID、作者不变，提高版本号。

`persona.json` 是唯一人设数据文件：

```json
{
  "schemaVersion": 1,
  "personaName": "小鱼",
  "age": 23,
  "job": "画家",
  "appearance": "",
  "personality": "沉静，熟悉后会开玩笑",
  "background": "",
  "customPrompt": "",
  "ownerName": "主人",
  "aliases": ["小鱼儿"],
  "masterRoast": true,
  "proactive": false,
  "opinions": true,
  "emoji": "正常",
  "emojiChance": 0.3,
  "privateMaxChars": 140,
  "groupMaxChars": 70,
  "historyTurns": 120,
  "groupHistoryTurns": 100,
  "maxBubbles": 2,
  "discussionMaxChars": 400
}
```

包名是清单 `Name`；角色名是 `personaName`。补充正文最多 24000 字符，人设文件最多 192 KiB，ZIP 最多 1 MiB。实际应用仍需模型输入预算校验。

## 公开上架边界

本客户端支持两种包；「仅分享提示词」的 persona.json 正文结构符合旧市场格式，但新导出清单包含 appCompatibility，仍需市场校验同步支持，不能保证整包直接通过。「打包分享」包含完整设置，支持本地安装。**目前市场仓库 `validate.py` 仍要求 persona.json 只有非空 customPrompt，文件不超过 64 KiB；完整设置包暂不能直接通过市场校验。**

市场需要同步：

- 在 `index-personas.json` 的纯数据校验中兼容旧正文格式及 `schemaVersion: 1`。
- 目录生成与包校验保留 appCompatibility，核对两代范围与包内声明一致；顶层仍保留旧代最低版本。
- 按上述字段白名单校验类型与范围；拒绝主人账号、权限、脚本和密钥字段。
- 有基础身份的新格式允许空正文；旧格式仍要求非空正文。
- 新格式最低客户端 4.1.5，人设文件上限改为 192 KiB，包内仍仅两个文件。
- 增加完整设置、空正文、非法类型、隐私字段和往返安装测试。

公开投稿仍只向 `Banan1cee/whale-girl-plugins:main` 提交，由市场审核生成目录。导出不会自动上传，本轮没有修改市场仓库或提交 PR。本地分享与安装无需 GitHub 账号。

## 新旧版本双兼容说明

迁移版 4.1.6.1 起，人设页导出的 ZIP 默认包含 `appCompatibility`，同一个包可供旧 4.x 和正式 1.x 使用。纯提示词的旧代最低版本为 4.1.0，完整设置为 4.1.5；正式代最低为 1.0.0。顶层 MinAppVersion 仍保留旧代最低版本，供不认识新字段的已发布客户端读取。

原来没有兼容字段的旧包不会自动视为正式代兼容，可由作者重新导出或明确声明两代范围。公开投稿仍需外部市场生成器、校验器同步支持，不能把本地可安装理解为市场已经接受新格式。字段示例见 [插件市场规范](插件市场规范.md)。
