# 启动器保存与接口测试核查

## 保存入口

| 页面 | 保存方式与本轮处理 |
| --- | --- |
| 状态 | 只读状态，无配置表单 |
| 人设 | 自动保存，读取期间校验编辑版本；周期刷新不回填表单 |
| 设置 | 串行保存；文本、数字、密钥和滑块保留待保存值 |
| 微信桥接 | 配置走统一保存入口；读取后不周期覆盖表单 |
| 发言范围 / 联系人名单 | 勾选保存，允许离线写入；失败显示错误 |
| 主动与提醒 | 再次进入只刷新状态，避免覆盖草稿；日记配置允许离线保存 |
| 朋友圈 | 自动策略串行保存；离页不清除发表配置草稿，旧请求不能回填 |
| 表情包 | 目录编辑及开关保存期间防止轮询旧值回填 |
| 语音发送 | 显式保存本机配置，已有 Key 测试；实际发送测试另行确认 |
| 插件市场 / 插件工具 | 保留插件原有配置、授权与执行入口，不用连接测试替代权限确认 |
| 诊断 | 维护操作需要确认，不自动执行重置、导入或清空 |

## 服务商 API 测试

- 聊天：先保存当前表单，再真实调用当前模型；演示模式不算连接成功。
- 看图：保存当前设置，再用内置测试图调用；请求等待时间调整为 60 秒。
- 语音识别：新增测试按钮，确认后选择最多 2 MiB 的 WAV；按桥接协议调用并要求有效转写，HTTP 200 空结果不算成功。
- DeepSeek 搜索 / 知乎搜索：各自独立测试，不使用另一服务商或本地搜索兜底；缺密钥、鉴权失败、限流和响应格式错误均失败。
- 语音发送：已有 API Key 测试和明确标注的文件传输助手实际发送测试，二者不能混称。

测试可能产生服务商费用。不会在批量回归中调用用户真实密钥或上传用户聊天、音频。自动化测试覆盖模拟成功/失败和 HTTP 接线，不代表当前网络下所有真实服务商均可用；真实可用性由用户点击测试确认。

本轮不迁移用户实际安装目录，也不覆盖用户配置；安装版需要同步新的内核源码与启动器。
