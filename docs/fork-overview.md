# Fork 说明：whale_girl 本地改进版（4.1.3-local）

基于 Banan1cee/whale_girl 官方 **4.1.3** 基线的 fork，长期跟踪上游并保留以下本地改进。
所有改动均有配套测试与 CHANGELOG 记录（见 `docs/CHANGELOG.md` 的 `4.1.3-local` 段）。

## 联网检索（与上游差异最大的一块，全部经真实网络实测）

- **双源并行**：bing + 360 首轮并行抓取合并——两家都会对程序化抓取间歇性返回广告/默认页，单源串行一旦中招整轮报废。
- **时效统计事实强制检索**：榜单/排名/冠军/销量这类逐年刷新的统计，语义路由误判"不用查"时强制检索（实测：问"CS去年top20"被跳过、拿 2024 记忆冒充 2025）。
- **相对时间锚定**："去年/今年/前年"按查询时刻换算成具体年份再搜；讲别的年份的证据直接判零分。
- **相关性过滤改造**：时间词不作锚点、不参与分词桥接；覆盖率相对阈值淘汰搭便车条目但绝不清空弱证据池。
- **名单/榜单类抓正文**：搜索摘要只有前几名，自动抓结果页正文。
- **口语疑问词放行**（干嘛/干啥/咋/啥系）进语义路由；纯陈述句不放行。
- 中国天气网主源（实况+预报+预警+AQI，区县级）+ 防限流缓存。

## 微信发送通道

- **静默发送**：打字期间把微信窗口挪到屏幕外坐标，屏幕上完全看不到；退出时还原。
- 文字改回车提交（点发送按钮会激活窗口）；发送后统一 `quiet_restore()` 还原窗口状态。
- 跨重启草稿自愈（最近发送正文落盘，看门狗重启后仍能认出并清掉残留）。
- 语音 uncertain 状态证据核对：只有微信数据库里真出现新语音才算送达，否则回落文字。

## 群聊理解

- 统一"谁在跟谁说话"仲裁器 `addressing.analyze()` + 影子模式（与旧判定分歧只记日志，收集样本后切换）。
- 引用消息解析（`reply_body` 区分本条正文与引用块）、botSpokeLast 接话信号、断句等待、表达单元抑制（文字+表情包只回一次）。
- 关心检测器：非召唤消息在表达关心时转为温柔回应。

## 其他

- RAG 知识库（BM25 中文检索，可信度高于联网）、看门狗心跳/dead_chats TTL、设置原子写、配置坏文件拒写。
- `scripts/package-portable.ps1`：一键生成剔除密钥与本机数据的通用便携包（含随包运行时）。
